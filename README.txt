LOVE DIARY — JAVASCRIPT-ONLY EDITION
====================================

WHAT "JAVASCRIPT ONLY" MEANS HERE
- The app's page content is generated by JavaScript.
- All visual styling is created by a CSS string injected from app.js.
- index.html is only a tiny browser entry point that loads app.js. A browser still needs an HTML entry point to run a website.

FEATURES
- Add multiple relationship records.
- Save partner name, exact start date/time, optional end date/time, and notes.
- Active records show a live days/hours/minutes/seconds counter.
- Past records use the saved end date/time.
- Dashboard shows total partners, combined elapsed days, active relationships, and saved memories.
- Search, filter, and sort relationship records.
- Upcoming relationship milestones and anniversary information.
- Memory journal with add, edit, delete, date, note, and partner association.
- Light/dark theme.
- Export and import JSON backups.
- Clear all saved data.
- LocalStorage persistence.
- PWA manifest and service worker for installation/offline app-shell caching.
- Responsive layout for phone, tablet, and desktop.

RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server or another local web server.
4. Open index.html through localhost.
5. Add relationships and memories.

PWA
PWA install requires HTTPS or localhost. It does not work by double-clicking index.html using file://.
- Android Chrome: browser menu > Install app / Add to Home screen.
- Desktop Chrome/Edge: use the install icon in the address bar if available.
- iPhone Safari: Share > Add to Home Screen.
For deployment, upload the folder to a static host such as Vercel.

HOMEWORK CONCEPTS
- JavaScript DOM: creates page elements and updates the page.
- JavaScript template literals: generate HTML markup.
- JavaScript event listeners: handle buttons, forms, search, filters, and dialogs.
- JavaScript Date: calculate relationship duration and milestones.
- JavaScript arrays/objects: manage relationship and memory records.
- JSON.stringify / JSON.parse: save and restore records.
- localStorage: persist information in the current browser.
- Service Worker + Web App Manifest: PWA installation and offline app shell.

DATA WARNING
This project stores information in LocalStorage on the current browser/device. It does not use a database, login, cloud backup, or cross-device synchronization. Export a JSON backup regularly. Clearing browser site data may delete saved records.

COUNTING RULE
The combined total is the sum of each relationship's elapsed whole days. Overlapping relationships are counted separately. Current relationships count up to now; past relationships count up to their saved end date.
